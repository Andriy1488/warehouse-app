# Лабораторна робота 3.2

## Робота з даними заявок

Для роботи із заявками створено окремий шар сервісів.
Компоненти отримують дані та виконують операції через контекст
`PlacementRequestsContext`.

### Тестовий сервіс

Файл `src/services/mockRequestService.js` імітує роботу сервера.
Він зберігає заявки у `localStorage` браузера, додає затримку
та дозволяє перевірити обробку помилок.

Після оновлення сторінки збережені заявки залишаються доступними
в тому самому браузері.

### Сервіс API

Файл `src/services/apiRequestService.js` підготовлено для роботи
із сервером через `fetch`. Він містить методи:

- `getAll` — отримання списку заявок;
- `getById` — отримання заявки за ID;
- `create` — створення заявки;
- `update` — оновлення заявки;
- `delete` — видалення заявки.

Сервіс очікує, що сервер надає маршрут `/placements`.
Роботу з реальним сервером поки не перевірено.

### Вибір джерела даних

Файл `src/services/requestService.js` вибирає сервіс за значенням
змінної `REACT_APP_DATA_SOURCE`.

За замовчуванням використовується тестовий сервіс. Для режиму API
потрібно встановити `REACT_APP_DATA_SOURCE=api` та вказати базову
адресу сервера у `REACT_APP_API_URL`.

## Стани інтерфейсу

На сторінках заявок передбачено повідомлення про завантаження,
помилку та можливість повторити запит. Під час збереження форми
поля тимчасово блокуються. Якщо збереження не вдалося, введені
дані залишаються у формі.

## Перевірка

Для запуску тестів використано команду:

```powershell
npm.cmd test -- --watchAll=false
```

Успішно пройшли два тести: перевірка порожньої форми та
створення заявки з появою в списку.
