# Реалізовані маршрути вебсайту розміщення товарів по складах

| Адреса | Сторінка | Звідки беруться дані | Якщо даних немає |
|---|---|---|---|
| `/` | Головна | Список складів із `inventory.js` | Показати повідомлення про відсутність складів |
| `/products` | Каталог товарів | Товари з `inventory.js`; пошук і фільтр із URL | Показати повідомлення, що товарів не знайдено |
| `/products/:productId` | Деталі товару | Знайти товар за `productId` з адреси | Показати повідомлення й посилання на каталог |
| `/placements` | Список демонстраційних заявок | Локальний масив заявок | Показати повідомлення про порожній список |
| `/placements/new?productId=...` | Нова заявка | Товар визначається параметром `productId` | Запропонувати вибрати товар у каталозі |
| `/placements/:placementId/edit` | Редагування чернетки | Знайти демонстраційну заявку за ID з адреси | Показати повідомлення й посилання на список |
| `/about` | Про нас | Статичний опис | — |
| Інша адреса | Сторінку не знайдено | — | Посилання на головну |

Стара адреса `/placement` перенаправляє на `/placements/new`.

Фільтри каталогу зберігатимуться в адресі, наприклад:
`/products?q=цемент&inStock=1`.
Таке посилання можна відкрити повторно й отримати той самий список товарів.

Заявки в цій лабораторній є демонстраційними. Заповнення форми не змінює
залишки на складах і не зберігає новий запис.
