# Реалізовані маршрути вебсайту розміщення товарів по складах

| Адреса | Сторінка | Звідки беруться дані | Якщо даних немає |
|---|---|---|---|
| `/` | Головна | Склади з `inventory.js` | Повідомлення про відсутність складів |
| `/products` | Каталог товарів | Товари з `inventory.js`, фільтри з URL | Повідомлення, що товарів не знайдено |
| `/products/:productId` | Деталі товару | Пошук товару за ID з адреси | Повідомлення й посилання на каталог |
| `/placements` | Список заявок | Спільний стан `PlacementRequestsContext`, пошук і фільтри з URL | Окремі повідомлення для порожнього списку й порожнього результату пошуку |
| `/placements/new?productId=...` | Створення заявки | Вибраний товар з URL або контексту; дані керованої форми | Повідомлення про помилки біля полів |
| `/placements/:placementId` | Деталі заявки | Пошук заявки за ID у спільному стані | Повідомлення й посилання на список |
| `/placements/:placementId/edit` | Редагування заявки | Дані заявки зі спільного стану | Повідомлення й посилання на список |
| `/about` | Про нас | Статичний опис | — |
| Інша адреса | Сторінку не знайдено | — | Посилання на головну |

Стара адреса `/placement` перенаправляє на `/placements/new`.

Пошук, склад і сортування заявок зберігаються в адресі, наприклад:
`/placements?q=цемент&warehouse=w2&sort=quantity-desc`.

Створення, редагування та видалення змінюють спільний стан React. Записи
зберігаються під час переходів між сторінками, але після оновлення вкладки
відновлюється початковий список. Залишки товарів на складах не змінюються.

Заявки в цій лабораторній є демонстраційними. Заповнення форми не змінює
залишки на складах і не зберігає новий запис.

## План ЛР 3.1 — заявка на розміщення товару

| Поле | Правило |
|---|---|
| `id` | Унікальний ID створюється під час збереження; у формі не змінюється |
| `productId` | Обов’язково вибрати товар, який є в каталозі |
| `warehouseId` | Обов’язково вибрати склад, який є у списку складів |
| `quantity` | Обов’язкове ціле число від 1 до 1000 |
| `positions` | Обов’язкове ціле число від 1 до кількості вільних місць на вибраному складі |
| `note` | Обов’язкова примітка: від 10 до 200 символів після видалення пробілів на початку й у кінці |

Створення, оновлення та видалення змінюватимуть одну спільну колекцію заявок.
Після перезавантаження сторінки колекція повертатиметься до початкових записів.
