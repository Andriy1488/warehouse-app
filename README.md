# Розміщення товарів по складах

Навчальний вебсайт на React для перегляду товарів і складів та роботи із заявками на розміщення товарів.

## Можливості

- Перегляд складів і каталогу товарів.
- Пошук і фільтрація товарів через параметри адреси.
- Створення заявки з вибором товару, складу, кількості, місць зберігання та примітки.
- Перевірка даних форми з повідомленнями біля полів.
- Перегляд, редагування й видалення заявок із підтвердженням видалення.
- Пошук заявок, фільтрація за складом і сортування за кількістю через параметри адреси.
- Повідомлення про успішне створення, оновлення та видалення.

## Маршрути

- `/` — головна сторінка зі складами.
- `/products` — каталог товарів.
- `/products/:productId` — сторінка товару.
- `/placements` — список заявок із пошуком, фільтром і сортуванням.
- `/placements/new?productId=p1` — створення заявки з вибраним товаром.
- `/placements/:placementId` — перегляд заявки.
- `/placements/:placementId/edit` — редагування заявки.
- `/about` — сторінка «Про нас».

Повна карта маршрутів є у [docs/project-plan.md](docs/project-plan.md).
