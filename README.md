# Розміщення товарів по складах

Навчальний вебсайт на React для перегляду товарів і складів та оформлення розміщення товару на складі.

## Можливості

- Перегляд головної сторінки, каталогу товарів, сторінки розміщення та сторінки «Про нас».
- Пошук і фільтрація товарів.
- Вибір товару в каталозі з передаванням вибору на сторінку розміщення.
- Введення складу та кількості через керовану форму з перевіркою даних.
- Попередній перегляд розміщення перед підтвердженням.
- Зміна назви вкладки браузера залежно від вибраного товару.

## Запуск

У папці проєкту виконайте `npm.cmd install`, а потім `npm.cmd start`.
Сайт відкриється за адресою http://localhost:3000.

Для перевірки збірки виконайте `npm.cmd run build`.
